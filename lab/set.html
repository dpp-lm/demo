The completions

Each point is a completion: direction = its meaning, length = √κ. Red: the set so far.

The kernel

Hover a cell: each one compares two vectors of the plot.

The set

    The matrix is the DPP's kernel L = diag(√w) G diag(√w): cell (i, j) is the inner product of the two drawn vectors (√κ_i φ_i · √κ_j φ_j for Most likely). Hovering a cell draws that pair in the plot, with the angle between them. Adding a completion conditions the DPP on it: the matrix shows L^A = L − L_{·A} L_A⁻¹ L_{A·} (what is left of each comparison once the set's directions are explained away), on the unconditioned colour scale and in a fixed row order. Hovering a row shows it as a candidate in the rail, with the factor by which it would multiply the set's volume (its leftover, det L_{A+i} / det L_A). A completion already in the span of the set cannot be added (factor 0).
